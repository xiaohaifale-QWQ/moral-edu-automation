# 德育分自动化系统 · AI 对接（MCP）

把「德育分自动化系统」接给任意支持 **MCP** 的 AI 客户端（Cherry Studio、Claude Desktop、Cursor、Trae 等）。
之后你可以直接跟 AI 说「吴东逃课扣20，方世杰五星寝室加1」，它会自己把记录填进软件。

---

## 一、目录里有什么

| 文件 | 作用 |
|---|---|
| `mcp_server.py` | MCP 服务本体。由 AI 客户端启动，不需要你手动运行 |
| `MCP配置.json` | 配置片段，导入 AI 客户端即可 |
| `使用说明.md` | 本文件 |
| `小欧-AI设定.md` | 给 AI 的人格设定。粘进 AI 客户端的系统提示词里，AI 就会变成「小欧」—— 一个嘴贫但账记得死板的德育分管家 |

运行时软件会在**程序目录**下自动建一个 `_ai_bridge\` 文件夹：

```
程序目录\
├── AI对接\              ← 本文件夹
├── _ai_bridge\
│   ├── state.json       软件写的当前状态（哪一周、是否在运行）
│   ├── inbox\           AI 排入的待导入记录
│   ├── done\            已导入的记录留痕
│   └── mcp_server.log   服务诊断日志
```

## 二、接入 AI 客户端

### 通用方式（大多数客户端）

1. 打开 AI 客户端的「MCP / 工具 / 扩展」设置
2. 找到「导入配置」「添加 MCP 服务器」之类的入口
3. 把 `MCP配置.json` **拖进去**，或把里面的内容粘贴进去
4. 保存后应该能看到一个名为 **deyufen** 的服务，显示 8 个工具

`MCP配置.json` 内容长这样：

```json
{
  "mcpServers": {
    "deyufen": {
      "command": "C:\\Users\\32570\\AppData\\Local\\Programs\\Python\\Python312\\python.exe",
      "args": ["……\\德育分自动化系统\\AI对接\\mcp_server.py"]
    }
  }
}
```

> ⚠️ 如果你把程序文件夹挪了位置，需要把 `args` 里的路径改成新位置。

### Cherry Studio

设置 → MCP 服务器 → 添加 → 从 JSON 导入 → 粘贴上面的内容。

### Claude Desktop

编辑 `%APPDATA%\Claude\claude_desktop_config.json`，把 `mcpServers` 那段合并进去，重启 Claude。

### Cursor / Trae 等

`~/.cursor/mcp.json` 或设置里的 MCP 面板，粘贴同样内容。

## 三、怎么用

打开 **德育分自动化系统**，把考评周期切到你要录入的那一周（这一步很重要，AI 会按软件当前周期写）。

然后在 AI 里直接说话：

> 吴东逃课扣20分，方世杰和冯弈尘五星寝室各加1分

AI 会调用 `add_records` 把记录排入队列（不用先查周期，服务端会自动用软件当前那一周）。

**软件大约 2 秒内会自动填入，并把该行高亮。** 然后你点「生成周表」就落盘了。

### 名字认不清也能对上（近似匹配）

拍照、手写、OCR 认错一两个字都不用改，直接把看到的原样发给 AI 就行：

```
冯弈臣五星寝室加1分        ← 名单里其实是「冯弈尘」
```

服务端会算相似度：**足够像就自动匹配**，并返回「近似匹配：原文「冯弈臣」，相似度 77%」。
软件里这类记录会显示成**橙色行**，明细里带「AI 原文：xxx，相似 xx%」，
页面顶部还有一行橙色图例提示你核对。

只有在「同时有好几个差不多像的人」时才会拒绝，那时 AI 会列候选让你写全名。

### 只报奖项、不报分数也行

你不需要自己算分，也不需要有意识地说分数 —— 说清奖项就行：

```
吴东省赛一等奖，方世杰国赛二等奖，冯弈尘五星寝室
```

服务端会按名单模板「加分预览」表自动取分：

| 你说 | 自动取分 |
|---|---|
| 省赛一等奖 | +10 |
| 国赛二等奖 | +10 |
| 市级三等奖 | +4 |
| 五星寝室 / 三星寝室 | +1 / -1（周·成员；说「室长」按室长算） |
| 早自习迟到 / 缺勤 | -0.5 / -1 |
| 活动类比赛一等 / 二等 / 参与 | +4 / +3 / +1 |
| 标兵、荣誉称号 | +4 |

返回里会标「模板取分：省级·一等奖」，软件里这条的**分值显示成青色**，
明细后面带「模板取分」或「模板 省级·一等奖」。取分不对就点那一行改。
实在查不到（比如「表现优秀」这种没标准的说法），才会拒绝并让 AI 补分数。

### 在软件里核对

记录写进来后，「AI 连接」页会把它们**逐条列出来**（学号后两位 / 姓名 / 加减分 / 明细）：

- **橙色行** = 姓名是近似匹配的，重点核对那几条
- **青色分值** = 分数是程序按模板查的，不是你说出来的，核对一下取值对不对
- **点任意一行** → 改这条的分值和明细，保存后立刻同步到「周纪实表」和「月度汇总」
- **点「驳回」** → 只删这一条，删错了还能点「撤回」恢复
- 页面顶部会显示当前周期一共收到几条、队列里还有几批没导入
- **寝室相关的记录会自动跳到「寝室统计」页**：写进来的是「五星寝室」「三星寝室」这类，
  软件直接把界面切到「寝室统计」，页面底部单独列一份「AI 写入的寝室记录」，
  同样支持点行修改和驳回。不用再点「应用打分」，那条已经写进本周了。

### 可用工具

| 工具 | 用途 |
|---|---|
| `add_records` | **写记录的主入口**：排入导入队列（姓名支持模糊匹配，分数可省略、自动按模板取分；`replace=true` 覆盖同人同明细，`batch_key` 防重发翻倍） |
| `undo_last` | 撤回最近 N 批 AI 写入（只对软件当前周期有效，切过周期就撤不到了） |
| `get_context` | 软件是否在运行、当前年月周、班级、人数 |
| `get_week_records` | 某一周已录入的记录（避免重复录） |
| `get_score_rules` | 加分标准表（竞赛等级、寝室星级、早自习） |
| `get_month_summary` | 某月各周累加与最终分 |
| `list_students` | 47 人名单（学号 / 姓名 / 寝室 / 角色） |
| `set_dorm_stars` | 设置寝室页的星级滑块（不直接打分，用户点「应用打分」才落库） |

### 给 AI 的提示词建议

**更省事的办法**：直接把 `小欧-AI设定.md` 整份粘进系统提示词，人格、工具、流程、评分标准都配好了。

如果想自己写一小段，粘这个：

```
你现在操作的是「德育分自动化系统」。
用户用自然语言描述的加减分，请直接调 add_records 写入，
不用先查周期，也不用先核名单：服务端会自动用当前周期，姓名也支持模糊匹配。
score 正数加分、负数扣分；一次不超过 50 条。
如果我只说奖项没说分数，就不要追问，直接不传 score，服务端会按模板自动取分。
如果返回里有「近似匹配」或「模板取分」，请把这个情况明确告诉我，让我去软件里核对橙色行和青色分值。
```

## 四、注意

- **软件没开也能用**：记录会先排队，等你打开软件并切到对应周次后自动填入。
- **整批要么全成功、要么全不写**：只要有一条彻底对不上（或名字太模糊），整批都会拒绝并告诉你原因，避免写一半。
- **近似匹配要人工过一眼**：橙色行是 AI 按相似度认的人，别直接点「生成周表」。
- **写入后记得点「生成周表」**：软件里的改动是内存态，只有生成才写进 Excel。
- 万一 AI 写错了，软件里点「撤回」即可（一次导入算一步）。

## 五、排错

**客户端里看不到 deyufen**
先用命令行验证服务本身是否正常：

```bat
"C:\Users\32570\AppData\Local\Programs\Python\Python312\python.exe" "……\AI对接\mcp_server.py" --selftest
```

能打印名单和规则说明服务没问题，检查配置里的路径和客户端日志。

**AI 说找不到学生 / 说名字太模糊**
说明相似度不够或有多个候选人。让它调 `list_students`，或者直接给它学号后两位。
名单里的姓名是模板中的写法，生僻字可能不同（`奕` 会自动按 `弈` 处理）。

**记录没出现在软件里**
1. 看 `_ai_bridge\inbox\` 里还有没有 `.json` —— 有说明还没被消费
2. 看软件的考评周期是否和记录里的周期一致（不一致会一直排队）
3. 看 `_ai_bridge\mcp_server.log` 是否有报错

**记录里的周期怎么看**
打开 `_ai_bridge\inbox\*.json`，里面有 `year / month / week` 三个字段。
