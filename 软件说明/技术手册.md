# 德育分自动化系统 技术手册

## 一、项目概述

德育分自动化系统是一个基于 Python Tkinter 的桌面应用程序，用于高校班级德育分的日常管理与自动化汇总。支持语音识别、图片 OCR、AI 语义分析。

### 1.1 技术栈

| 层级 | 技术 | 版本 | 用途 |
|------|------|------|------|
| GUI 框架 | Tkinter | Python 内置 | 桌面界面渲染 |
| 表格处理 | openpyxl | 3.1+ | Excel 读写、模板操作 |
| 数据处理 | pandas | 3.0+ | 模板解析 |
| 语音识别 | OpenAI Whisper | base 模型 | 本地中文语音转文字 |
| 录音 | sounddevice | 0.4+ | 麦克风音频采集 |
| 音频解码 | ffmpeg | latest | Whisper 音频预处理 |
| 图片 OCR | PaddleOCR | latest | 图片文字识别 |
| AI 分析 | DeepSeek API | deepseek-chat | 自然语言结构化提取 |
| 打包 | PyInstaller | 6.20 | EXE 生成 |
| 版本管理 | Git | 2.54 | 代码版本控制 |

## 三、关键算法

### 3.1 周表生成算法（原子级动态克隆与拼接）

```
输入: base_layout[] = [(左学号, 右学号), ...]
输出: 周纪实表.xlsx

对每个学生对子 (l_id, r_id):
  1. l_recs = week_data[l_id]['records']
  2. r_recs = week_data[r_id]['records']
  3. block_rows = max(1, len(l_recs), len(r_recs))
  4. total_extra_rows += block_rows - 1
  5. 写入左学生: 学号(合并) + 分数 + 原因
  6. 写入右学生: 学号(合并) + 分数 + 原因
  7. 少记录一方下端空单元格合并对齐
  8. 签名区整体下移 total_extra_rows 行
```

### 3.2 MergedCell 读取修复

```
问题: 周表中合并单元格(学号列)导致后续行分数丢失
原因: openpyxl 中 MergedCell.value = None，原代码判断 None 即跳过
修复: 追踪 active_sid，遇到 MergedCell 沿用上一个学号
```

### 3.3 学生匹配算法

```
优先级: 精确匹配 → 模糊匹配 → 多选弹窗
1. kw == name 或 kw == sid → 直接使用
2. kw in name → 模糊匹配(单人不弹窗)
3. kw.isdigit() → 学号尾号匹配(sid.endswith(kw.zfill(2)))
4. 多人 → 弹窗选择
```

### 3.4 撤回 / 重做

```
操作 → undo_stack.push(deepcopy(week_data))
        redo_stack.clear()
撤回 → redo_stack.push(deepcopy(week_data))
        week_data = undo_stack.pop()
重做 → undo_stack.push(deepcopy(week_data))
        week_data = redo_stack.pop()
```

## 四、线程模型

所有耗时操作使用后台线程 + 主线程消息队列：

```
主线程 (Tkinter 事件循环)
  │
  ├── UI 交互
  ├── _flush_recog_queue() (200ms 定时器)
  │   ├── recog_text 日志刷新
  │   └── recog_tree 表格刷新
  │
  └── 启动后台线程:
      ├── _record_audio      (录音)
      ├── _transcribe_audio  (Whisper 转写)
      ├── _do_image_recognition (PaddleOCR)
      └── _call_deepseek     (API 调用)
           │
           └── _log_recog() → 消息队列 → _flush_recog_queue()
```

**线程安全规则**:
- Tkinter 控件操作仅在主线程
- `simpledialog` 仅在主线程调用
- 耗时操作通过消息队列异步更新 UI
