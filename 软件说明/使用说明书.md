# 🌸 德育分自动化系统 使用说明书

## 一、快速开始

### 1.1 文件准备

将 `德育分自动化系统.exe` 和 `名单模板.xlsx` 放在**同一文件夹**内。

### 1.2 名单模板结构

`名单模板.xlsx` 必须包含以下 5 个 Sheet：

| Sheet | 内容 | 示例 |
|-------|------|------|
| 月表模板 | 学号 + 姓名 + 班级名 | 230101 / 张三 / 23级计算机1班 |
| 寝室名单 | 寝室号、成员、室长 | 101 / 张三,李四 / 王五 |
| 周表模板 | 左右排版 | 决定周表排列顺序 |
| 周表模板2 | 签名区 | 底部考评签名 |
| 加分预览 | 加减分规则 | 迟到:-1 / 早自习:+1 |

### 1.3 首次运行

双击 EXE，自动读取模板，显示班级名称即成功。

## 二、三个界面的用途

软件顶部有两个切换按钮：

```
[切换到：周纪实表界面]  [切换到：月度汇总界面]
```

### 📋 周纪实表界面 — 日常使用

**功能**：
- 手动加分（支持模糊搜索）
- 寝室星级批量评定
- 双击编辑已有记录
- 一键生成周表 Excel

**手动添加入口**：
```
┌─ 手动添加记录 ────────────────────────────────┐
│ 姓名:[____]  原因:[____]  分值:[____]  [添加] │
└───────────────────────────────────────────────┘
```

输入姓名（支持缩写）、原因、分值（支持表达式如 `10+2`），点添加或回车。

### 📊 月度汇总界面 — 月末使用

**步骤**：
1. 自动读取本月所有周次
2. 导入上个月总表作为底分
3. 生成月度总表

**首月模式**：勾选后每人默认 80 分底分。

### 🌸 懒人模式 — AI 辅助

点击 `⚡ 进入懒人模式` 按钮进入。

**三种输入方式**：

| 方式 | 操作 | 原理 |
|------|------|------|
| 🎤 语音 | 点开始录音 → 说话 → 点停止 | Whisper 转文字 → AI 分析 |
| 📷 图片 | 点图片识别 → 选图片 | OCR → AI 分析 |
| 💬 文字 | 输入框打字 → 发送 | 直接 AI 分析 |

**AI 工作流程**：
```
你的输入 → Whisper/OCR → 原始文本
    ↓
AI 获得: 学生名单 + 加减分规则
    ↓
AI 返回: JSON 格式记录
    ↓
显示在识别记录表 → 点确认 → 写入周表
```

## 三、手动加分详解

### 3.1 姓名输入方式

| 输入 | 匹配效果 |
|------|---------|
| 完整姓名 `张三` | 精确匹配 |
| 名字片段 `三` | 含"三"的学生 |
| 数字 `2` | 学号尾号 02 的学生 |
| 数字 `12` | 学号尾号 12 的学生 |

匹配到多人会弹出选择窗口。

### 3.2 分值输入

支持直接数字或表达式：
- `-1` → 扣1分
- `10+2` → 加12分
- `3*4` → 12分

### 3.3 双击编辑

在预览表中**双击**某学生的"总加分"或"项目明细"，可直接修改：
- 总加分 → 差值加到末条记录
- 项目明细 → 修改原因文字（`|` 分隔）

### 3.4 撤回 / 重做

工具栏 `← 撤回` 和 `→ 重做` 按钮，支持多步撤销恢复。

## 四、寝室星级评定

在懒人模式左侧：

```
🌸 寝室星级评定
[🌸 读取周表]         ← 从文件恢复
[✔️ 应用寝室星级打分]  ← 生效
[🌸 显示识别记录]     ← 预览加减分
```

**规则**：

| 星级 | 成员 | 室长 |
|------|------|------|
| 5星 | +1 | +1 |
| 4星 | 0 | 0 |
| 3星 | -1 | -1.5 |

## 五、模板修改

**改名单/规则无需改代码**：

1. 直接编辑 `名单模板.xlsx`
2. 点工具栏 `🔄 刷新模板`
3. 软件自动同步

## 六、AI 功能配置

### 6.1 获取 API Key

1. 访问 https://platform.deepseek.com
2. 注册并获取 API Key
3. 首次使用 AI 时弹窗输入

### 6.2 首次使用

- 语音：自动下载 Whisper + ffmpeg（~230MB）
- 图片：自动下载 PaddleOCR（~500MB）
- 仅首次需等待，后续秒开

## 七、常见问题

| 问题 | 解决方法 |
|------|---------|
| 文件被占用 | 关闭 Excel 中的目标文件，点重试 |
| 名字打不上分 | 检查模板中姓名是否一致，点刷新模板 |
| API 反复弹出 | 检查 deepseek_config.json 是否存在 |
| 语音识别报错 | 确保麦克风正常，首次需下载模型 |
| 图片识别报错 | 首次需下载 PaddleOCR，需联网 |
| 月度汇总只统计第一行 | 已修复，更新至最新版 |
